## How to Use This Repository

1. Start with the document most relevant to the problem you are solving.
2. Use the materials as references during ideation, validation, product planning, and implementation.
3. Adapt the guidance to your project's requirements rather than treating every instruction as universally applicable.
4. Improve the library over time by adding well-organized, useful knowledge.

## Contributing to Your Own Knowledge Base

When adding documents:
- Use descriptive filenames.
- Keep related material organized.
- Update this index when adding or renaming documents.
- Never commit API keys, passwords, access tokens, private keys, or confidential information.
